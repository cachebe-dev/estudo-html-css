Principais Formatações

Negrito / destaque

nessa frase temos um texto em negrito usando a tag <b> (não semântica)

nessa frase temos um texto em negrito usando a tag <strong> (semântica)

Itálico / ênfase

nessa frase, temos um termo em itálico usando a letra <i> (não semântica)

nesta frase temos um termo em destaque usando a tag <em> (semântica)

podemos marcar textos com a tag <mark>

podemos reduzir o tamanho do texto com a tag <small>, a tag <big> já não é recomendada

podemos marcar um texto como excluído com a tag <del> para indicar que ele deve ser lido, mas não deve ser considerado

podemos marcar um texto como inserido com a tag <ins> para dar ênfase, indicando que ele foi adicionado

existe também a tag <u> para sublinhar textos (não semântica)

texto sobrescrito <sup> - para inserir coisas como x20 + 3

texto subscrito <sub> - para inserir coisas como H2O
